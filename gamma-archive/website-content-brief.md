Prepared: 2026-04-19

## Background

This document consolidates 43 Gamma presentations archived from Matthew's gamma.app account into a curated set of unique content pieces, mapped to the existing and proposed sections of theethicaleducator.com. The full archive with all originals is preserved separately (see Archive Location section at the end). Nothing has been deleted or modified.

The site currently has seven content sections: About, Moral Psychology, AI & Ethics, AI in Education, Philosophy in K-12, Thought Experiments, and Resources. It is academic and philosophical in tone, focused on the intersection of moral philosophy, ethics, and AI in education.

The Gamma presentations fall into a different register. Most are practitioner-facing professional development materials: workshop decks on feedback strategies, Danielson Framework walkthroughs, student engagement techniques, and operational guides. Integrating them will require either adapting the content to match the site's voice or creating new sections that acknowledge this PD-oriented material as a distinct offering.

## Recommended Integration Strategy

The presentations exist as PDFs, PPTXs, and structured JSON content extracts. The website project has several options for integration, roughly ordered from lightest to heaviest lift:

**Option A: Downloadable resources.** Add PDFs and PPTXs as downloadable files in the Resources section or a new "PD Materials" section. Minimal effort. The site links to them; users download and use.

**Option B: Embedded presentations.** Gamma presentations can be embedded via iframe using the format `https://gamma.app/embed/{gamma_id}`. This preserves interactivity (embedded videos, forms, collaboration tools) and keeps the content live. The JSON content extracts provide the metadata needed to build index pages.

**Option C: Content extraction and rewrite.** Use the JSON content extracts to pull the text and restructure it as native site content (HTML sections, blog posts, or interactive components). This is the highest-effort option but produces the most cohesive result. The content extracts have card-by-card summaries that make this feasible without manually opening each presentation.

**Recommended approach:** A hybrid. Use Option B (embedded Gamma) for the PD materials in a new "For Educators" section, and Option C (extract and rewrite) for the 3-4 presentations that align closely with existing site sections (AI Ethics, AI in Education). This gets the most content onto the site quickly while investing rewrite effort only where it matters most for voice consistency.

## Archive Location

All original files are preserved in the gamma-archive folder structure:

```
gamma-archive/
  metadata/
    inventory.csv              — Master list of all 43 items (number, title, gamma_id, URL, type, last_viewed, topic)
    export-urls.json           — All 86 export download URLs (43 PDF + 43 PPTX)
    flags-report.md            — Flags for embedded media, large files, interactive elements
    categorization.md          — Full categorization table with 6 categories
  content-extracts/
    01_*.json through 43_*.json — Structured JSON for every presentation (titles, card summaries, flags)
  raw-exports/
    (empty in sandbox — files downloaded to user's Downloads folder as numbered PDF and PPTX files)
  download-exports.sh          — Re-runnable script to download all 86 files via curl
```

The 86 exported files (43 PDFs + 43 PPTXs) are in Matthew's Downloads folder, named with the pattern `{number}_{title}.{pdf|pptx}`.

The JSON content extracts in `content-extracts/` are the most useful asset for the website project. Each file contains the presentation title, card count, card-by-card titles and content summaries, and flags for embedded media. These provide enough detail to build index pages, write descriptions, or plan content extraction without opening each presentation individually.
